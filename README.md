# Telegram Bot для мастера по маникюру

Этот бот позволяет пользователям записываться на услуги маникюра, просматривать прайсы и портфолио. Администратор может управлять расписанием.

## Установка зависимостей

1. Установите Python 3.8 или выше.
2. Клонируйте репозиторий или скачайте файлы.
3. Установите зависимости:

```bash
pip install -r requirements.txt
```

## Настройка

1. Создайте бота через @BotFather в Telegram и получите токен.
2. Создайте канал для проверки подписки и канал для расписания.
3. Отредактируйте `config.py`:
   - `BOT_TOKEN`: ваш токен бота
   - `ADMIN_ID`: ваш Telegram ID (можно получить через @userinfobot)
   - `CHANNEL_ID`: username канала для подписки (например, @your_channel)
   - `CHANNEL_LINK`: ссылка на канал (например, https://t.me/your_channel)
   - `SCHEDULE_CHANNEL_ID`: username канала для расписания

## Запуск

```bash
python bot.py
```

## Структура проекта

```
telegram-bot-example/
├── bot.py                 # Основной файл бота
├── config.py              # Конфигурация
├── database.py            # Работа с базой данных SQLite
├── scheduler.py           # Планировщик напоминаний
├── handlers/
│   ├── user_handlers.py   # Хендлеры для пользователей
│   └── admin_handlers.py  # Хендлеры для администратора
├── requirements.txt       # Зависимости
└── README.md              # Этот файл
```

## Функционал

- Запись на услуги с выбором даты и времени
- Проверка подписки на канал
- Отмена записи
- Прайсы и портфолио
- Админ-панель для управления расписанием
- Автонапоминания за 24 часа
